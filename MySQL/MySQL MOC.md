# MySQL MOC

이 영역의 입구. 지금까지의 핵심 축은 **"스키마를 서비스 멈추지 않고 바꾸는 법, 그리고 그걸 가능케 하는 밑바탕"** — MySQL 8.0의 [[데이터 딕셔너리]]가 스키마의 단일 출처를 트랜잭션 안전하게 들고 있기에 무중단 DDL이 성립한다.

## 읽는 순서

1. [[데이터 딕셔너리]] — 먼저. DB가 스키마를 스스로 적어두는 카탈로그. 아래 둘의 토대.
2. [[INSTANT DDL]] — 행에 버전을 달고 읽을 때 통역. 물리 재작성 없이 즉시 스키마 변경.
3. [[온라인 DDL]] — INSTANT/INPLACE/COPY를 무게순으로 나란히 놓고 본 지도.

## 곁가지

- [[복합키로 PK 를 설정할 시 불리함들]] — 위 DDL 흐름과는 결이 다른, PK·인덱스 설계 주제.
