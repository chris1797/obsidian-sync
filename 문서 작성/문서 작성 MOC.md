# 문서 작성 MOC

> 핵심 축: 코드를 읽어도 알 수 없는 것만 남긴다 (무엇을 담고 → 앞세우고 → 어떤 형태로)

## 읽는 순서

1. [[문서에 남길 것]] — 무엇을 담을까.
2. [[문서에서 무엇을 먼저 말할까]] — 무엇을 앞세울까.
3. [[구조 없는 나열]] — 어떤 형태로 담을까.
4. [[정본 스냅샷]] — 정본이 레포 밖에 있을 때의 예외.

## 가지
- [[문서에 남길 것]] — 코드에서 파생 가능한 것은 파생시키고, 계산되지 않는 것만 문서에 저장한다
